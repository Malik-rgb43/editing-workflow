# B01 — Hebrew / English talking head, 45 s

> Status: **specified, not run.** Brief version 0.1, written 2026-10-02 from BENCHMARK_SUITE_SPEC §3 (research T13, 2026-10-01). Synthetic assets only (the generator contract below); no client or real-person material. Specified; model eval not run (decision default Q4). No threshold here is validated; acceptance thresholds belong in a preregistered owner contract.
> Companion: `talking-head.rubric.md`, `critic-brief.md`, `bands.json`. Exists in a **Hebrew form (B01-he)** and an **English form (B01-en)** of equivalent task complexity — the Hebrew script is written natively, **not machine-translated**.

## 1. Task

Edit a **45 s vertical (9:16, 1080×1920, 30 fps) talking-head piece** from the frozen inputs. Preserve **every material claim** (numbers, negations, currency, dates); make **accessible captions**; use **motivated reframes** (punch-in/out on emphasis, smooth centred camera); include **one explanatory visual beat** (the station map, below). Deliver `final/b01_<lang>_9x16.mp4` + `manifest.json` + the run record. The author runs the normal gated workflow (wf-00 … wf-08), with a scripted "owner" supplying the answers in `inputs/answers.json` so intake is reproducible.

## 2. Frozen inputs (generator contract — `fixtures/generators/b01/`)

| Input | Specification | Notes |
|---|---|---|
| speech | **original recording by the test author (consent record in `fixtures/manifest.json`) or a local synthetic TTS voice (licence recorded)**; ≈ 45 s of speech with natural pauses; one take with 2–3 deliberate retakes/false starts to test cutting; clean + a noisy variant is **not** part of B01 (see B05) | the speech is *frozen*: no re-recording between arms |
| video of the speaker | a **synthetic speaker plate**: a generated, moving, mouth-animated silhouette on a plain background (ffmpeg-generated), 1080×1920 or 1920×1080 at 30 fps, with a declared **face-safe region** (JSON box) and a declared colour state | face-detector-based tools (`face_center`, `color_check`) cannot judge a silhouette → their status is `not_run` **with the reason**, never `PASS`. A second arm may use an owned, consented real recording |
| transcript + timing | **manually checked** transcript, `transcript.<lang>.txt` and word times `cues.<lang>.json` (rational times) | ground truth for sync and caption checks |
| claims table | `claims.json`: every number, currency, negation, date and proper noun with its expected on-screen/caption form | below |
| palette / fonts | `design_seed.json`: 4 hex colours + OFL fonts (Rubik, Heebo) with licence files | |
| station-map data | `stations.json`: 42 points on a synthetic coastline for the one explanatory visual | the visual may be a map animation, a counter or a diagram — author's choice, but it must carry the 42 |

**Script (English form, 119 words; fictional place and product):** "Last spring our town launched Pedala, a bike-sharing pilot. There are 42 stations, from the harbour to the university. A day pass costs 12 shekels, and the first thirty minutes of every ride are free. There is no deposit and no registration fee. You do not need an app to unlock a bike: you can pay by card at any station. The pilot runs for six months, from March third to September third. Every tenth ride is on us. Bikes are not allowed on the ferry on weekends. Stations are open around the clock, but support is available only from seven in the morning until ten at night. Try it once, and see how fast the city feels."

**Script (Hebrew form, native):** "באביב האחרון העיר שלנו השיקה את ״פדלה״ — פיילוט של אופניים שיתופיים. יש 42 תחנות, מהנמל ועד האוניברסיטה. יום שימוש עולה 12 ש״ח, והחצי שעה הראשונה בכל נסיעה חינם. אין פיקדון ואין דמי רישום. לא צריך אפליקציה כדי לשחרר אופניים: אפשר לשלם בכרטיס בכל תחנה. הפיילוט נמשך שישה חודשים, מה־3 במרץ עד ה־3 בספטמבר. כל נסיעה עשירית היא על חשבוננו. אסור להעלות אופניים על המעבורת בסופי שבוע. התחנות פתוחות מסביב לשעון, אבל התמיכה זמינה רק משבע בבוקר עד עשר בלילה. נסו פעם אחת, ותראו כמה העיר נעשית מהירה."

`claims.json` must list at least: **numbers** (42; 12 ש״ח / 12 shekels; thirty minutes; six months; 3 March; 3 September; every tenth; 7:00; 22:00), **negations** (no deposit; no registration fee; no app needed; bikes not allowed on the ferry on weekends; support *only* 7:00–22:00), **currency** (₪ / ש״ח placement), **proper noun** (פדלה / Pedala — fictional) and **mixed-script** items (Latin brand + digits inside Hebrew). Everything is invented; no real service is described.

## 3. What is measured

| Outcome (suite spec) | Deterministic check | Human check | Notes |
|---|---|---|---|
| copy / negation / number correctness | caption text vs `claims.json` (normalised diff, exact on digits and negation words); a missing/inverted negation or a changed number is a **severe failure** | Hebrew/English reader checks every claim on frames | OCR only if captions are rasterised |
| sync | caption cue times vs `cues.<lang>.json` (early/late reported separately; rational times; tolerance defined before scoring) | listening | no universal ms tolerance is established |
| caption geometry | collision solver ([caption-collision.md](../../techniques/caption-collision.md)) on the declared layout manifest; rail ≤ y 1450; key text inside the safe zone | phone-scale look | collision-free ≠ legible |
| voice intelligibility | loudness −14 ± 0.5 LUFS, TP ≤ −1 on the final file (house preset); VO margin ≥ 5 dB in 1–4 kHz if music is used | listener transcript test | |
| motion stability | `motion_qa` coverage + status; `camera_path` smoothness if a face path exists | playback | `INSUFFICIENT_EVIDENCE` is allowed and reported |
| human comprehension | — | unaided transcript/comprehension questions **before** feedback; randomised order, arm names hidden | no participant count is invented — choose from a pilot's variability |

**Hard gates:** claims table fully satisfied (no severe failure); delivery gate (length ±1 frame, black, edge band); every required QA tool reports `PASS` *or* `not_run`/`unsupported` **with a reason** (never a silent pass).

## 4. Constraints

No paid action. Local tools only. One heavy job at a time. Fixed export settings; the same machine profile and cache state for both arms. The author may not edit the frozen inputs.

## 5. Run record (per arm)

`brief_id` B01 / version / language · author identity (human, or exact model + effort + context/skills hashes + tool profile) · environment (OS, CPU/GPU, RAM, versions, power mode, cache state) · UTC + local start/end, **per-stage monotonic durations**, queue wait, active authoring, setup/download time, wall time, **render count**, retries · stage result envelopes · final artifact SHA-256 · review block (human vs model, blinding, inspected ranges, rubric version, scores, abstentions, disagreement) · coverage (decoded vs expected frames; image-sampled intervals; human playback coverage). **Null is not 0.**

## 6. Limits

A synthetic silhouette cannot test face-centring, skin colour or real lip-sync; a TTS voice tests intelligibility but not natural breathing; a single-take script cannot test restructure decisions. These are stated, not hidden. Results from this brief say nothing about real footage until the held-out natural-video corpus (an open gate) exists.
