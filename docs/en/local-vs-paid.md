# Local or paid - what replaces what, and where each download comes from

> Read on **2026-10-03** from the hosts themselves (Hugging Face API, GitHub release headers, PyPI, the model READMEs, `hyperframes <command> --help` of the pinned 0.8.98). Sizes are the exact byte counts the host reported. URLs, sizes and licences are perishable: re-read before you rely on them.

## local-vs-paid-01 - How to read this page
The installer **never downloads model weights**. Every row below that has a download is a separate yes from you, with the size shown first, and nothing is fetched until you say so. "Local" means it runs on your computer for free (you pay in time and electricity); it does not mean "as good as". Where there is no local replacement, the table says so instead of inventing one.

## local-vs-paid-03 - What you actually have to approve
1. **Hebrew transcription**: one download of about 1.6 GB, once. Without it `analyze` and the captions skill run as "not run", never as a pass.
2. **Speaker cutout**: the first `cutout` run on the native route downloads about 176 MB (the tool tells you before it starts). The MODNet route is a 26 MB file you place yourself.
3. **Faces**: a 233 KB file, only if you use `face_center`.
4. Everything else in the table is either already part of the toolkit (`analyze`, `ui`, `hf_blocks`, `cutout` code) or paid and optional.

## local-vs-paid-04 - How this was checked, and what was not
Checked on 2026-10-03: the Hugging Face file lists and sizes, the GitHub release sizes (response headers), the PyPI version and licence field, the MODNet and RVM repositories' licence statements, the OpenCV zoo folder licence, the Kokoro model card and voice list, and the pinned `hyperframes tts`/`remove-background` help text. **Not checked**: the licence of the u2net_human_seg weights as such, the quality of any model on your footage, speed on your computer, and any price (prices live in dated reference modules and change). Nothing in this table is a legal opinion.
