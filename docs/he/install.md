# התקנה - מה קורה, מה יורד, ועל מה עונים

> נכתב ב-2026-10-03. המתקין (`install/bootstrap.py`) נבדק בבדיקות אוטומטיות עם הדמיות, רץ ב-CI על Windows, macOS ו-Ubuntu, והותקן פעם אחת משכפול נקי על מחשב one reference machine. התקנה נקייה על macOS ועל Linux **עדיין לא** נבדקה. ההוראות של הסוכן נמצאות ב-[INSTALL.md](../../INSTALL.md), והדף הזה הוא אותו תהליך בשבילך. אנגלית: [docs/en/install.md](../en/install.md).

**שני ריפואים, שני לינקים.** קודם `claude-code-setup` (מכין את Claude Code: חוסך קרדיטים, מוסיף דפדפן וכלי סקילים). אחר כך **הריפו הזה**, ארגז הכלים לעריכה. מדביקים את הלינק ב-Claude Code או ב-Codex ואומרים "תתקין את זה". הסוכן מזהה את המחשב **בעצמו**, ואף פעם לא שואל אותך על כרטיס מסך, זיכרון או מערכת הפעלה.

## install-01 - פותחים את הסוכן ומדביקים את הלינק
פותחים את Claude Code או Codex בכל תיקייה, מדביקים את הלינק של הריפו וכותבים "תתקין את זה". אם כותבים בעברית, כל השיחה בעברית. לא צריך הרשאות מנהל; ייתכן חלון אישור אחד אופציונלי של Windows (UAC) אם מאשרים התקנת Node או Git. אם Claude Code לא הוכן עם `claude-code-setup`, הסוכן יזכיר את זה פעם אחת, ואפשר להמשיך גם בלי.

<!-- step: install-02 -->
## install-02 - הסוכן מוריד את ארגז הכלים
הוא משכפל את הריפו לתיקייה **באותיות אנגליות בלבד** (בלי עברית בנתיב), למשל `C:\Users\<name>\editing-workflow` או `~/editing-workflow`. אין Git? הוא מציע להתקין Git או להוריד ZIP של אותו לינק; הוא אומר לך קודם את שם הקובץ והגודל ומחכה לכן שלך. הוא גם מוצא Python שעובד (`py -3`, `python`, `python3` או `uv run --python 3.12`); ה"python" של חנות Microsoft ב-Windows מתעלמים ממנו.

<!-- step: install-03 -->
## install-03 - הסוכן מזהה את המחשב (קריאה בלבד)
הפקודה `python install/bootstrap.py plan` מזהה: מערכת הפעלה, ארכיטקטורת מעבד (x64 או arm64), ליבות, זיכרון, מקום פנוי, יצרן כרטיס מסך (NVIDIA, AMD, Intel, Apple Silicon או אין/וירטואלי) ו-shell; אילו דרישות קיימות (Git, FFmpeg כולל קידוד קטן **אמיתי** של H.264+AAC, Node 22+, npm, uv, סוכני ה-CLI); אילו סקילים יועתקו והאם יש לך סקיל באותו שם; מה יורד; העלות (אפס) וחסמים. היא לא משנה כלום.

<!-- step: install-04 -->
## install-04 - הבחירות שזוהו (לא שואלים אותך)
המתקין בוחר את ההתקנה הבטוחה ביותר שעובדת בכל מחשב:
* **בסיס**: סקילים + FFmpeg + הכלים של הערכה + מנוע HyperFrames, **בלי חיבורים**. בלי חשבון, מפתח, כרטיס מסך או תשלום.
* **תמלול**: מסלול מעבד מקומי (`asr-cpu`, faster-whisper int8) זמין ומותקן **רק אם תבחר מקומי** בשלב הבא. משקלות המודל לא יורדים אף פעם עד שאישרת את הגודל.
* **חיתוך דובר מהרקע**: המסלול של המנוע על המעבד, בלי התקנה נוספת.
* **מקודד וידאו**: `libx264` על המעבד, מוכח בקידוד הניסיון האמיתי.
* **מסלולי GPU מהירים** (CUDA, Vulkan, Apple): יוצעו בתוך הבחירה המקומית כשאלה *אופציונלית*, **רק אם הבדיקה שלהם עברה**, עם תווית "לא נמדד" או "נמדד על מחשב אחד".
* חיבורים, ספקים, Blender, Premiere/After Effects: לא מותקנים בהתקנה עצמה. אלה הבחירות שלך ב-install-05 וב-install-10.

<!-- step: install-05 -->
## install-05 - איך אתה רוצה לעבוד: מקומי, מחובר או שניהם?
השאלה היחידה על "איך", **בלי ברירת מחדל**. זו בחירה של סגנון עבודה, לא שאלה על החומרה שלך.
* **מקומי** - כל מה שאפשר להריץ על המחשב שלך, בחינם: תמלול בעברית עם מודל מקומי, חיתוך דמות מהרקע, כלים חינמיים לסרטוני רפרנס. הסוכן מוריד מה שצריך לזה (משקלות המודל רק אחרי שאישרת את הגודל).
* **מחובר** - שירותים אונליין עושים את העבודה הכבדה של ה-AI (קול, יצירה, חומרי סטוק ...) ו**אתה בוחר מרשימה** למה להתחבר עכשיו.
* **שניהם** - הכלים המקומיים ועוד השירותים שבחרת.
מה שלא תבחר, ההתקנה הבסיסית זהה (סקילים, כלים, HyperFrames, חבילות בדיקת איכות). אפשר לשנות דעה בכל רגע, ואפשר לחבר עוד אחר כך פשוט בכתיבה: "תחבר את <שירות>".

<!-- step: install-06 -->
## install-06 - מאשרים פעם אחת
הסוכן מספר לך, בעד 15 שורות: מה זוהה; **מה יורד לפי דרך העבודה שבחרת** (הטבלה למעלה); מה משתנה במחשב (סקילים, תיקיית הכלים `~/.avc/toolkit`, תיקיית עבודה באנגלית, הערה קצרה וניתנת להסרה בקובץ ההוראות של הסוכן); העלות (אפס); על אילו שאלות תישאל; ואיך מבטלים. אחר כך **שאלה אחת**: "להמשיך עם התוכנית? (כן/לא)".

<!-- step: install-07 -->
## install-07 - ההתקנה רצה (כאן מותקן HyperFrames)
`bootstrap.py apply --yes`: תיקיית הכלים, הסקילים (נלקח **גיבוי** לפני שמחליפים משהו; סקיל שלך באותו שם מדולג אלא אם אישרת `--force`), ההערה המסומנת, תיקיית עבודה באנגלית + `toolkit.local.toml`, `uv sync --no-dev`, **מנוע HyperFrames** (`npm ci --ignore-scripts` מתוך `package.json` ו-`package-lock.json`, גרסה 0.8.98), סביבת התמלול על המעבד (רק אם בחרת מקומי; משקלות לא יורדים) ובדיקת קישורים. בטוח להריץ שוב: מה שהסתיים מדולג. שלב שנכשל לא דורש ניקוי ידני.

<!-- step: install-08 -->
## install-08 - כלים שחסרים
אם התוכנית מציינת כלי חסר, היא מראה את הפקודה המדויקת למערכת שלך ומאיפה היא באה. דוגמאות (נבדקו ב-2026-10-02): ב-Windows `winget install --id Gyan.FFmpeg -e --source winget`, ב-macOS `brew install ffmpeg`; Node LTS: `winget install --id OpenJS.NodeJS.LTS -e --source winget` או `brew install node@24`. אתה בוחר אם הסוכן יריץ אותן. אחר כך פותחים **טרמינל חדש** כדי שה-PATH יתרענן, והסוכן מריץ את ההתקנה שוב.

<!-- step: install-09 -->
## install-09 - HyperFrames: דפדפן ובדיקה
HyperFrames מרנדר בדפדפן Chrome ללא ממשק. הסוכן שואל לפני שהוא מוריד אותו, ואז מריץ `hyperframes browser ensure` ו-`hyperframes doctor --json`. אם "Docker" או "whisper-cpp" מופיעים כ"לא נמצא", זה בסדר; הם אופציונליים. HyperFrames פותח על ידי HeyGen: https://github.com/heygen-com/hyperframes. הפרויקטים שלך יושבים בתיקיית עבודה באנגלית בלבד, כי `hyperframes init` מדלג על קבצים בנתיב עם אותיות עבריות.

<!-- step: install-10 -->
## install-10 - מה לחבר
אחרי שההתקנה עובדת הסוכן שואל, **בחירה אחת בכל פעם**. שום דבר לא מסומן מראש; "כלום" ו"לא עכשיו" הן תשובות לגיטימיות.
* **אם בחרת מקומי:** התוספות המקומיות החינמיות - סרטוני רפרנס מלינקים (YouTube, TikTok, Instagram), חיתוך דמות מהיר יותר (`matte-fast`), תמלול מהיר יותר על כרטיס המסך (רק אם במחשב שלך זוהה מסלול מהיר שעובד), ו-Blender לתלת-ממד (Three.js לא דורש התקנה).
* **אם בחרת מחובר (או שניהם):** רשימה לבחירה, כמה שתרצה או אף אחד.
  | קבוצה | שירותים | עלות |
  |---|---|---|
  | קול ויצירה ב-AI | ElevenLabs, Higgsfield | **בתשלום** |
  | חומרי סטוק | Pexels, Iconify | מסלול חינמי |
  | רכיבי UI | shadcn; 21st.dev | חינם; בתשלום |
  | תלת-ממד | מחבר Blender (בונה התלת-ממד כברירת מחדל); יצירת מודלים ב-AI עם Tripo, בשימוש רק אם חיברת אותו | Blender חינם; יצירה בתשלום |
  | עורכי וידאו | גשרים ל-Premiere Pro ול-After Effects | הרישיון שלך ל-Adobe |
  על כל שירות שבחרת הסוכן מסביר מה זה וכמה זה עולה, ואז מראה לך את **לינק ההרשמה**. חלק מהלינקים הם לינקי הפניה: הם מסומנים "לינק הפניה", הלינק הרגיל מוצג לצידם, ואתה יכול לבחור באחד מהם או לדלג. הסוכן לא פותח שום דבר בלי שאמרת כן.
* **לחבר עוד אחר כך - פשוט לכתוב.** בכל שיחה מאוחרת יותר כותבים "תחבר את ElevenLabs" (או כל שירות); הסוכן מריץ `add` ומראה את לינק ההרשמה באותה דרך.

<!-- step: install-11 -->
## install-11 - דברים שרק אתה עושה (כשמוסיפים משהו)
* **כניסה למחברים** (Higgsfield, ElevenLabs): בסוכן מקלידים `/mcp`, בוחרים את השרת וגומרים את הכניסה בדפדפן.
* **מפתחות API** (Pexels, 21st.dev): יוצרים את המפתח באתר הספק ושומרים אותו כ*משתנה סביבה של המשתמש* בשם המדויק מהקטלוג. ב-Windows: התחל -> "Edit environment variables for your account" -> New. ב-macOS: מוסיפים `export NAME=...` ל-`~/.zshrc` בעורך טקסט. אף פעם לא מדביקים מפתח בצ'אט ולא משתמשים בקידומת `!` של הסוכן. אחר כך מפעילים את הסוכן מחדש.
* **תוספים מקוריים** (גשרי Premiere / After Effects, התוסף של Blender): אתה מוריד ומתקין מהספק.
כניסה לחשבון לא עולה כסף. הוצאה תמיד עוברת בשער ההוצאות.

## install-12 - מאמתים ומפעילים את הסוכן מחדש
הפקודה `python install/bootstrap.py verify` בודקת מחדש כל קובץ מותקן מול המניפסט, מריצה בדיקת קישורים, חוזרת על קידוד הניסיון של FFmpeg ומדפיסה את חמשת המצבים. `claude doctor` מאבחן רק את התקנת Claude Code ואינו הוכחה שוידאו עובד. אחר כך **מפעילים מחדש את הסוכן** ושואלים "אילו סקילים יש לך על וידאו?" - `course-router` חייב להופיע.

## install-14 - הדוח, חמשת המצבים, והוספת חיבורים אחר כך
הסוכן מסיים בדוח קצר: **מה הותקן ומה ירד**, **מה רק אתה צריך לעשות**, **איך מבטלים או מעדכנים**. חמשת המצבים מדווחים עם ראיות ולא מתמזגים: (1) מותקן - (2) חשבון מאושר - (3) רינדור ראשון - (4) בדיקה עברה - (5) מוכן ליצירה בתשלום. `not_run` אינו מעבר.
אפשר להוסיף חיבורים גם אחר כך, אחד אחד:
```text
python install/bootstrap.py add --list
python install/bootstrap.py add <id>
python install/bootstrap.py add <id> --yes
```
הפקודה `add <id>` מציגה קודם תוכנית לקריאה בלבד (מה זה, עלות, לאן הולכים הפרטים, לינקי הרשמה, שלבים שרק אתה עושה); עם `--yes` היא עושה רק את החלק הבטוח שלא עולה כסף. היא אף פעם לא קוראת או שומרת מפתח, לא נכנסת לחשבון, לא מורידה משקלות מודל ולא מוציאה כסף.

<!-- step: install-15 -->
## install-15 - אם משהו נכשל
מריצים שוב את אותה פקודה; היא ממשיכה מהמקום שבו עצרה. קוד יציאה 4 = חלקי: קוראים את השורה שנכשלה. ראה [פתרון בעיות](troubleshooting.md). לביטול: [הסרה](uninstall.md) או `rollback` ([עדכון וחזרה אחורה](update-rollback.md)). אף פעם לא שולחים מפתח כדי לקבל עזרה; שולחים את שורת השגיאה אחרי ניקוי ואת `python install/bootstrap.py verify --json`.

## שימוש ידני בלי סוכן
```text
git clone <repository link> "<ASCII folder>"
cd "<ASCII folder>"
python install/bootstrap.py plan
python install/bootstrap.py apply --yes
python install/bootstrap.py verify
```
ב-Windows PowerShell 5.1 אין תמיכה ב-`&&`: מריצים פקודה אחת בכל שורה. עוטפים נתיבים במרכאות כפולות ב-PowerShell, ב-CMD וב-bash.
